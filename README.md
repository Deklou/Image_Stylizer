# Image Stylizer

Application Windows pour styliser des images avec différents effets et visualiser le résultat avant l'export.

## Lancer le projet

Installer les dépendances Python :

```powershell
python -m pip install -r requirements_build.txt
python main.py
```

## Créer l'exécutable Windows

Lancer `CONSTRUIRE_EXE_UNIQUE.bat` depuis la racine du projet.
Le fichier obtenu se trouve dans `dist_unique/`.

Les presets et préférences restent enregistrés localement sur le PC.
